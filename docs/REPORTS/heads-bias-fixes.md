# Classifier bias / weight-imbalance fixes

Decoupling / cRT / τ-normalization ([1910.09217](https://arxiv.org/abs/1910.09217), ICLR 2020), iNaturalist-2018, ResNet-50, 200 epochs, top-1: joint 65.8, cRT 68.2, τ-norm 69.3, LWS 69.5. Few-shot split: 61.7 → 66.1 → 69.3; many-shot: 75.7 → 73.2 → 71.1. Rebalancing is worth +7.6 on tail and costs −4.6 on head: favourable for macro, not for micro, where we are already 0.075 behind
Logit adjustment ([2007.07314](https://arxiv.org/abs/2007.07314), ICLR 2021) is the principled version; Table 1 + Figure 2 attack the weight-norm family: weight normalization is not Fisher-consistent for balanced error and relies on rare-class weight norms being smaller — an assumption "sensitive to the choice of optimiser". Balanced error (lower better): iNat ERM 38.66, weight-norm τ=1 48.05 (worse than ERM), weight-norm τ=τ* 34.10, post-hoc LA 33.98, LA loss 33.64; CIFAR-10-LT 27.16 → 19.08; ImageNet-LT 53.11 → 49.56. A 2–7 point gain from subtracting log-priors.
Cosine classifier / weight normalization: helps when it changes training dynamics, hurts as a post-hoc rescale with the wrong τ. No credible vision evidence at 12k labels
Classifier weight decay: we use 0, the bar 1e-3. Shrinking weight norms in a long-tail setting is the bias mechanism, so raising wd more likely worsens tail under-scoring than fixes it
The bound: post-hoc τ-normalization, post-hoc logit adjustment, per-class bias init and "cosine at inference" are per-class monotone rescalings of the current logits, capped by the measured oracle 0.3879 (a global shift by 0.3575). Applying them during training escapes the bound; after the fact cannot
